# Keyboard Shortcuts

Quick reference for all keyboard shortcuts wired in Unwrap v0.1.

## Global

| Shortcut | Action |
|---|---|
| Cmd/Ctrl+K | Open command palette |
| Esc | Close palette or modal |

## Command palette (built-in commands)

| Shortcut / Command | Action |
|---|---|
| Cmd/Ctrl+\ | Toggle inspector panel |
| Cmd/Ctrl+/ | Focus tree filter input |

## Asset tree (when tree panel is focused)

| Shortcut | Action |
|---|---|
| Arrow Up / Down | Move selection up / down |
| Right Arrow | Expand selected folder row |
| Left Arrow | Collapse selected folder row |
| Enter | Open selected row in a new tab |

## Tab bar

| Shortcut | Action |
|---|---|
| Cmd/Ctrl+W | Close active tab |

## Code preview (when Monaco editor is focused)

| Shortcut | Action |
|---|---|
| Cmd/Ctrl+E | Export decompiled source as .cs file |

## Deferred (planned for v0.2)

| Shortcut | Action | Status |
|---|---|---|
| Cmd/Ctrl+O | Open project folder via dialog | v0.2 |
| Cmd/Ctrl+R | Reload / rescan project | v0.2 |
| Cmd/Ctrl+F | Find in current preview | v0.2 (Monaco built-in) |
| Cmd/Ctrl+Shift+E | Export all decompiled sources | v0.2 |
